Dual-Lane Memory Core 0.1.0-alpha 测试说明
================================================

这个包只测 Python 记忆核心。
不需要 QQ、SnowLuma、DSH，也不需要任何 API key。
需要 Python 3.10 或更高版本。

一、解压
------------------------------------------------
把 zip 解压到一个空目录。
下面的命令都在“解压后的目录”里执行。

二、确认 Python
------------------------------------------------
PowerShell 里运行：

  python --version

如果没有 python，可以试：

  py -3 --version

三、跑测试
------------------------------------------------
在项目根目录运行：

  python -m unittest discover -s memory_core/tests

正常结果应包含：

  Ran 39 tests
  OK

四、初始化
------------------------------------------------
运行：

  python -m memory_core init

它会在 memory_core/ 下生成：
  config.json
  memory.db
  api-token
  admin-token

这些文件只保存在你本机，不要发回给我。

五、启动本地服务
------------------------------------------------
运行：

  python -m memory_core serve

保持这个窗口打开。
服务默认监听：http://127.0.0.1:9881

六、另开一个 PowerShell 验证
------------------------------------------------
运行：

  Invoke-RestMethod http://127.0.0.1:9881/health

再运行：

  python -m memory_core extract "我现在在玩只狼，卡在苇名弦一郎"

应该看到一条 game_progress 事实。
